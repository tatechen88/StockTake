# 數量盤點 StockTake

> 寫給還在為了「這材料我分身身上還有多少」而切換角色翻背包的老玩家。

## 為什麼你會想要它

玩了這麼多年，倉庫早就不是「一個角色的倉庫」了——是**一個帳號的倉庫**。精煉藥劑在德魯伊身上、礦石在法師背包裡、戰隊銀行還壓著一堆寶石。以前想知道「我到底有多少個這玩意兒」，不是切角色翻背包，就是裝個像 BagSync 那種大傢伙。

這個插件只做一件事：**滑鼠移到物品上，直接告訴你全帳號誰有多少**。裝上就能用，沒有設定精靈、沒有相依函式庫，一共 5 個檔案。

## 它長這樣

把滑鼠移到任何物品上（背包裡、銀行裡、拍賣場、聊天連結都行），提示資訊會在遊戲原生說明後面多出幾列：

```
虛觸強化符文
物品等級 350
使用：智力提高 25 點，持續 1 小時。
"可以在拍賣場購買和出售。"
                        ← 空一列，跟遊戲內容隔開
老頭一個:  27     （背 20 · 銀 7）
                        ← 你自己那一列下面有條紅線，一眼找到
霜火之誓:  12     （背 12）
鐵爐守衛:   3     （背 3）
合計: 42
                        ← 再空一列，其他插件的內容排在下面
售價: 264 96 20
```

![數量盤點：提示資訊效果（圖為簡體中文介面；角色名已打碼）](docs/images/tooltip-zhcn.png)

幾個順手的細節，都是實戰磨出來的：

- **你的目前角色永遠在第一列**，名字下面一條紅線，掃一眼就知道哪個是自己；
- **括號全部對齊成一條直線**——數量位數差再多（3 / 12 / 170）也不會歪，這是按像素排的欄位，不是補空白蒙混；
- **「銀」已經包含戰隊銀行**。帳號銀行裡的存貨不會漏，也不會跟角色銀行重複計算——你不用再心算「戰隊裡還有幾個」；
- 角色名按**職業顏色**顯示，跟團隊框架一個習慣；
- 位置排在**遊戲原生說明之後、其他插件（Auctionator 的售價之類）之前**——不用把長長的提示資訊拉到最底才找到數量。

## 設定（就三樣，多一樣都嫌煩）

**ESC → 選項 → 插件 → 數量盤點**，或者直接 `/st`：

| 設定 | 說明 |
|---|---|
| 顯示合計列 | 那一列「合計: 42」，不要可以關 |
| 提示資訊字型大小 | **整份提示資訊**的字型大小（包括遊戲自帶的文字）。預設「跟隨遊戲」＝裝上什麼都不改 |

下面還有一欄**「顯示哪些角色」**，它就是控制「其他角色」的唯一開關：練廢的分身、已經刪掉的角色還留著紀錄？把勾去掉，提示資訊立刻清爽；**全部取消勾選＝只看你自己**。目前角色永遠顯示，去不掉（那是你的主線資料）。

## 老玩家關心的問題

**為什麼有的角色不顯示數量？**
每個角色得**登入過一次**才會被記錄（背包在登入時記，銀行在打開銀行時記）。新練的分身先上一次線就有了。

**戰隊銀行怎麼算的？**
併進目前角色的「銀」裡，走的是暴雪官方的 `includeAccountBank` 參數，即時準確。其他角色各自只算自己的角色銀行，所以合計不會重複。

**身上的裝備算在哪？**
不算在「背」裡（「背」只數背包），單獨顯示為「裝備」。所以只戴著一件、沒有備品時，你看到的是
`名字: 1     （背 0 · 裝備 1）`——它明確告訴你：包包裡沒有多餘的。
裝備即時計入的只有**目前角色**這一列；其他角色只記錄背包與銀行快照，他們身上的裝備
不計入所在列，也不計入合計。

**資料存在哪？怎麼清空？**
`WTF\Account\帳號\SavedVariables\StockTake.lua`，只存物品 ID 和數字，不存名字圖示，不連網。想徹底重來，關掉遊戲刪掉這個檔案即可。

**會不會跟我的 UI 套件打架？**
預設只往提示資訊**加自己的列**，不改縮放、不動別人的列。唯一例外是字型大小滑桿——它是全域的（你要求的），如果你用了會改提示資訊字型的皮膚插件，兩邊可能互相覆蓋；滑桿留在「跟隨遊戲」就相安無事。

**記憶體佔用大嗎？怎麼瘦身？**
執行時佔用很小：滑鼠停留結果的快取有硬上限（最多 128 筆，滿了自動淘汰最舊的），掛一整個晚上也不會慢慢變大。真正會隨角色數量累積的，是各角色記下的背包／銀行清單——`/st clean` 一鍵清掉久未登入的角色（預設 30 天，`/st clean 60` 就是 60 天）。注意清掉的只是「多久沒上線的角色」的紀錄；想徹底重來，還是關掉遊戲刪掉 SavedVariables 檔案（見上面那條）。

**想看看其他語言長什麼樣？**
`/st zh` 簡體中文、`/st tw` 繁體中文、`/st en` 英文，都是**即時切換**（不用重新載入）；`/st auto` 跟隨客戶端語言。繁體中文客戶端會自動使用繁體中文。

## 安裝

把 `StockTake` 資料夾丟進 `World of Warcraft\_retail_\Interface\AddOns\`，重新啟動客戶端或 `/reload`。沒有別的了。
（插件列表裡顯示的名稱是**數量盤點**；資料夾名稱只是內部識別，不影響使用。）

## 我的另一個插件

**CraftPro（材料記錄）** —— 打開配方按一下按鈕，就得到一張材料清單：這張配方要什麼、你手上有多少（背包、銀行、材料銀行、戰隊銀行）、還缺多少；點一下材料列直接到拍賣場搜尋。

StockTake 告訴你有多少，CraftPro 告訴你要缺什麼，兩個搭著用正合適。
