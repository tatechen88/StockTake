### audit-v097 —— 0.9.7 装备计数链路（当前版本）

三个独立审计员（与编写者不同路由，只读）分别从代码正确性、口径与文档、测试与装置三个角度审计，
Lead 统一裁决修复。**结论：P0 = 0，P1 = 0**；接受 P2×3（文档披露×1 + 测试强度×2）与 P3×8，
全部处置或记入待办；疑点 E2（衬衫/战袍是否被 `GetItemCount` 统计）待真机数据。
测试 215 → **228** 用例全绿，两条关键修复均经变异验证（红过）。
