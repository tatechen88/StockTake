### 6.1 第一轮（全量审查）

- P0：**0** —— 对四条最可能出 P0 的路径（初始化竞态、计数重复/误清空、taint、跨模块符号）逐行推演均安全。

- P3：7（死代码、范围漂移、绕过 `Get:Config`、冗余二次 Show、重复 `ApplyGlobalFonts`、中文兜底、初始重复 Fire）→ 已修 4 项，其余记录在 §16.3。
- **16 项"已排查且无问题"**：材料银行 `depositFlags=0x80` 实核存在、`SetMinimumWidth` 12.x 存在、战团 `grand` 无重复、bank/reagent 互斥分桶、防误清空自愈、装备槽 1..19、`C_Timer` 跨 reload 无残留、订阅不重复、`SL.player` nil 防护、初始化顺序、`sameFactionOnly` 自洽、本地化 123=123、taint 安全、`MenuUtil`/`Settings` 用法、BackdropTemplate 九宫格等。

### 6.2 第二轮（5 方向受限复审）

- **方向 1 taint/战斗安全**：无缺陷（全程 `hooksecurefunc`/`HookScript`，无原生方法替换，且有 `IsForbidden` 防护）。
- **方向 2 反覆盖机制**：文本指纹碰撞概率极低（保留为待实测）；**"记录表随悬停无限增长"经核实不成立**（弱键表 + 整体替换）；`queryCache` 无上限 → **已修**。
- **方向 3 初始化竞态**：登录早期 `BAG_UPDATE` 首扫因 `charKey=nil` 被丢弃但**自愈**（`PLAYER_ENTERING_WORLD` 的 `ScanAll` 兜底）；`C_Timer` 跨 reload/换角色无残留。
- **方向 4 性能/内存**：`global.items` 无生命周期 → **已修**；装备图标 API 误判（前提不成立，仍做防御性归一）。
- **方向 5 enUS 键名外泄**：无缺陷（`T:L(key,fallback)` 正确抑制）。

### 6.3 审计给出但**有意不修**（记录在案）

1. **P3-4 的"单帧闪烁/多余布局开销"**：保留再 `Show()` 是因为皮肤插件会在 OnShow 覆盖字体，代价仅每轮一次布局，且 `reapplying` 守卫防递归。
2. **F4.3 银行 tab 数据缓存**：`FetchPurchasedBankTabData` 在银行不可交互时返回 nil，跨轮缓存会让材料页判定短暂回退到 `bank`——正是 M1 要测的路径，收益仅省 1–2 次 pcall，**接受现状**（决策注释已写入 `Scanner_Bank.lua`）。
3. **FIFO 顺序扫描边界**：顺序扫 576 个互不相同物品时命中 0（有界缓存 + 非 LRU 的固有行为）；未命中仅多一次 `Counter:Query`（其自身有缓存），真实悬停模式不受影响。
4. **`×`（U+00D7）关闭字形**：保留（暴雪字体覆盖 + 原生通用符）。
