## 1. 装置方案

- **执行引擎：fengari 0.1.5**（纯 JS 的 Lua 5.3 VM），配合本机 Node v24.19.0。
- 本机**没有 Lua 解释器**，fengari 经 `npm install fengari` 装入 `tools/` 后可用，**无需降级到静态契约校验器**。
- 架构三层：
  1. `tools/wow-mock.js` —— WoW 12.x API 无头模拟层。建一个 fengari 状态机，注入与规划第三章"已冻结 API 事实"一致的全局环境（`Enum.BagIndex` 命名成员真实数值、`C_Container.GetContainerItemInfo` 返回含 `itemName` 的 table、`C_Bank.FetchPurchasedBankTabIDs(bankType)` 返回 BagIndex 数组、`Enum.BankType={Character=0,Guild=1,Account=2}` 等）。**全部 mock 支持"可编程场景"**：测试可塞入假背包/银行/战团/装备数据、触发事件、手动 tick `C_Timer`；所有调用被记录。
  2. `tools/smoke-test.js` —— 按 `.toc` 顺序加载插件（跳过注释/指令行），注入 `SL_DB`，按契约 §2 触发 `ADDON_LOADED` → `PLAYER_ENTERING_WORLD`，再运行断言集；含极简断言框架与按套件统计。
  3. `tools/tests/` —— 断言集 + `tests/stub/`（最小参考实现，用于证明装置本身可运行）。

- 关键工程决策：插件文件头是 `local ADDON_NAME, SL = ...`（WoW 客户端把 `(插件名, 插件表)` 作为 chunk vararg 传入），因此 harness 对每个文件 `lua_pcall` 时推入 `("StackLedger", _G.StackLedger)` 两个实参；跨文件共享同一 addon 表，测试断言经全局 `StackLedger.*`（`SL` 是各文件局部变量，非全局）读取。

## 4. 发现的缺陷 / 需 Lead 裁决项

### D-1（唯一）：`template` 默认值与冻结契约 §8 不符 —— 契约版本漂移

| 项 | 位置 | 内容 |
|---|---|---|
| 冻结契约 | `CONTRACT.md` **L168** | `template` 默认 = `"{char}: {total}（背 {bags} · 银 {bank} · 穿 {equip}）"` |
| 插件实现 | `UI\Theme.lua` **L257** | `template = ""`（注释"v1.1：空串 = 跟随语言"） |
| 插件本地兜底 | `Tooltip.lua` **L39** | `template = ""`（同类 v1.1 注释，见 L24） |

- **现象**：我按冻结契约写的原始 `config`/`template` 断言产生 **3 处失败**，全部指向此漂移：
  1. `defaults.template` 实际 `""` ≠ 契约完整串；
  2. `SL_DB.profile.template` 迁移后同样 `""`；
  3. 契约 §8 默认模板渲染结果为 `""`。
- **期望**：`SL.Config.defaults.template` 与契约 §8 L168 完全一致（键值逐项冻结，§8 明言"defaults 冻结"）。
- **说明**：插件与并发 tooltip-layer 测试方均已在按 **"契约 §8 v1.1"**（`template=""` + 新增 `SL:GetConfig` 等 §14.1 符号）工作，但**冻结 CONTRACT.md 尚未更新**。这属于契约治理问题而非数据层 bug。
- **待 Lead 裁决**：① 把 CONTRACT.md 升级到 v1.1（认可 `template=""` 与 §14.1 符号），则测试断言随之对齐；或 ② 回退插件 `UI\Theme.lua:257` / `Tooltip.lua:39` 到 v1 冻结值。

> 协调说明：`tests/tooltip.js`（§7/§8-v1.1 端到端注入）及 `config.js`/`template.js` 的 v1.1 断言由并发 tooltip-layer 测试 Agent 在我交付后补充/改写，故当前合并态对真插件 160/160 通过；对 v1 风格的最小 stub 则按预期出现 9 处 v1.1 相关失败（stub 未实现 TIP_DEFAULT_TEMPLATE 词条、去重、作用域守卫等 v1.1 行为）。我负责的 6 个版本无关套件不受影响。
